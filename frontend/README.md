# Transit Buddy website

One static page (`index.html`, no build step) published to GitHub Pages by `.github/workflows/pages.yml`.

- Live URL: `https://tharunyasundar.github.io/TransitBuddy/`
- Preview locally: open `frontend/index.html` in a browser.
- The "Add to Discord" button uses the invite URL at the top of the `<script>` block in `index.html`
  (client id `1563757020832858132`, scopes `bot applications.commands`).
- The students and schedules in the demo are made up.
